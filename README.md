# QA67 Phonebook API

This project contains automated API tests for the Phonebook backend application.

The tests are written in Java. OkHttp is used for sending HTTP requests, and Gson is used for converting Java objects to JSON and JSON responses back to Java objects.

## Technologies

- Java
- Gradle
- TestNG
- OkHttp
- Gson
- Lombok
